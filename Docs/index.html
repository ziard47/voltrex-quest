Architecture & Modules

Built with native Windows 11 components.

Every screen runs on MVVM ViewModels, local JSON storage, and Windows process APIs without cloud accounts or external telemetry.

Home Dashboard

Displays live counts for saved games and catalog availability alongside recently played sessions and recently added library entries.

Discover Games

Searches the bundled gamelist.json catalog locally by name, alias, or executable with Windows and Overlay filters in a 4-column card grid.

My Games Library

Persists added titles, play counts, and custom launch paths in library.json with sorting, search, and Steam URI fallback.

Game Session Monitor

Opens a dedicated WinUI 3 companion window showing Process ID, process name, lifecycle state, elapsed duration, and safe session termination.

Dummy Game Runner

Includes a zero-dependency Win32 C++ stub executable copied on demand under the target binary name (such as wwm.exe) for local testing.

GitHub Releases Updater

Checks ziard47/voltrex-quest directly from Settings, previews release notes in a modal dialog, and runs the Inno Setup installer.

Quick Start

Install and launch in three steps.

01

Run the Windows Installer

Download Voltrex-Quest-Setup-win-x64.exe and install per-user or system-wide. The .NET 8 and Windows App SDK runtimes are bundled.

02

Add Games to My Games

Filter Discover Games by name or support tag and add titles to your personal library without modifying the read-only catalog.

03

Launch & Monitor Sessions

Select a local .exe, launch via Steam, or run the dummy game window while tracking real process state and history.
